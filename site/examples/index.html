Add an exampleFour steps

It runs, it's public, it's on Tablo.

That is the whole bar. A live deployment is welcome, not required: a repository with a run command is enough.

  1. Capture the app at 1600 by 1000 pixels, as WebP, into site/assets/captures/.
  2. Copy an <article> in site/examples/index.html and fill it in.
  3. Tag it live, template or repo, as many as apply.
  4. Open a pull request titled docs(repo): list <name> in the examples.
