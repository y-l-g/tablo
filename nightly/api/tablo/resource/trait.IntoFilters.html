Trait IntoFilters 

Source 
pub trait IntoFilters<M> { }
Expand description

Convert a single built-in filter, or a tuple of any Filters, into a table’s filter list.

A tuple takes filters of any type, an app’s own among them; a single app filter is a one-element tuple, (MyFilter,). Arity eight is the shared ceiling IntoColumns documents.

Dyn Compatibility§

This trait is dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
