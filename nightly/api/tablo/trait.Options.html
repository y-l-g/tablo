Expand description

A closed set of stored values, each with its label.

Derive it on a unit-variant enum with #[derive(Options)]: each variant stores its snake_case name and reads as its name in sentence case, and #[option(value = "..", label = "..")] overrides either.

ⓘ
#[derive(tablo::Options)]
enum Status {
    Draft,
    #[option(label = "Live")]
    Published,
}

Field::choice(Post::fields().status()).options(Status::options())
SelectFilter::r#for(Post::fields().status(), Status::options())
TextColumn::r#for(Post::fields().status(), |p| Status::label_of(&p.status))

The derive also gives the enum value(), label() and from_value(), so code that writes the column names a variant rather than a string.
