Expand description

One table column: what its header says, what each row’s cell shows, and which query predicates it contributes.

The built-in TextColumn and BooleanColumn implement this trait and nothing more, so an app column has the same reach: implement it, and pass the value to Table::new in a tuple or to Table::column.

ⓘ
struct Initials;

impl Column<User> for Initials {
    fn name(&self) -> &str { "initials" }
    fn label(&self) -> &str { "Initials" }
    fn text(&self, row: &User) -> String {
        row.name.split_whitespace().filter_map(|w| w.chars().next()).collect()
    }
}

Only name, label and text are required. The cell defaults to the text, and a column contributes no search, sort or relation until it says so.

fn cell<'a>(&self, cx: &'a Cx, row: &M) -> Pin<Box<dyn View + 'a>>

The row’s table cell. Defaults to text.

The cell sits in a td that truncates, so a view wider than its column clips to an ellipsis.

Source

fn column_width(&self) -> ColumnWidth

The width the column claims in the table’s fixed layout. Defaults to ColumnWidth::Narrow.

Source

fn is_searchable(&self) -> bool

Whether the column joins the table’s search: the search toolbar renders when any column does. Defaults to false.

fn search_expr(&self, _term: &str) -> Option<Expr<bool>>

The predicate a search for term adds, OR-ed with the other searchable columns’. term is trimmed and not empty. Defaults to none.

Whether the header links to a sort on this column. Defaults to false.
