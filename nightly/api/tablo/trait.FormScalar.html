Expand description

A type one form key reads and writes: String, every TypedValue type, and an Option of either.

The value the parse sees is trimmed and non-empty; an empty submission is the field’s blank answer instead (the blank a record form declares, else "" for String or None for an Option).

A text field binds a path of any FormScalar type (Field::text), and the form derives read and write every field that is not #[form(embed)] through it.
