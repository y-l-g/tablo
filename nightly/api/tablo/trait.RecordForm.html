Expand description

The typed value a resource’s form submission parses into.

Derive it with tablo_core::RecordForm; a hand-written impl is what the derive expands to.

Provided Associated Constants§

Source

const HAS_FORM: bool = true

Whether the resource naming this form has create and edit pages.

Panel::resource registers the create, edit, and options routes only when this holds. NoForm sets it to false.

fn into_update<'a>( self, record: &'a mut Self::Model, named: &HashSet<Self::Field>, ) -> Option<<Self::Model as Model>::Update<'a>>

The instance update builder with one assignment per named field, or None when no field is named.

None is what keeps a submission that names no field from building an empty update, which toasty refuses with an assertion.

Source

fn exec_update<'a>( update: <Self::Model as Model>::Update<'a>, ex: &'a mut dyn Executor, ) -> impl Future<Output = Result<(), Error>> + Send + 'a

Execute a builder Self::into_update returned.

Toasty’s instance update builder implements no trait that carries exec, so the generic write reaches it through the form.
