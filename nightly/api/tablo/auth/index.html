Module auth 

Source
Expand description

Authenticates panel users and gates panel routes.

Gates panels by default; installs PasswordAuth or a custom Authenticator. Reads the signed-in user through user and require_user. Stores sessions in AuthSession for every authenticator, scoped to the issuing panel.
