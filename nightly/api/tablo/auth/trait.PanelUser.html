Expand description

A signed-in user, as the panel knows it (ADR-0013).

Implement it for the app’s own user type and return that type from an Authenticator; the shipped AdminUser implements it too. App code reads the user back with its own type through user.

ⓘ
impl PanelUser for Staff {
    fn user_id(&self) -> String { self.id.to_string() }
    fn display_name(&self) -> &str { &self.name }
    fn can_access_panel(&self) -> bool { self.active }
    fn tenants(&self) -> &[Membership] { &self.memberships }
}

Provided Methods§

fn can_access_panel(&self) -> bool

Whether the user may enter the panel. A user who may not answers 403, indistinguishable from bad credentials at login. Defaults to true.

Source

fn tenants(&self) -> &[Membership]

The tenants the user may act for, in the order the tenant switcher lists them. The first is the default tenant until the user selects another. Defaults to none: the user has no tenant.
