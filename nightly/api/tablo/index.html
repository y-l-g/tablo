Tablo — an admin toolkit for Rust, server-rendered on Topcoat and persisted with Toasty.

This crate is the one Tablo dependency an app names, beside topcoat and toasty at the revisions Tablo pins. It re-exports tablo_core at its root, the UI components as ui, and, with the testing feature, the in-memory HTTP client as testing. The derives (RecordForm, EmbeddedForm) work through this crate alone.

[dependencies]
tablo = { git = "https://github.com/y-l-g/tablo", features = ["sqlite"] }

[build-dependencies]
tablo-build = { git = "https://github.com/y-l-g/tablo" }

The driver features (sqlite, postgresql, mysql) turn on Toasty’s driver of the same name; the toolkit itself enables none. The app’s build.rs calls tablo_build::tailwind(), which finds Tablo’s sources through this crate. The user guide starts at “Your first panel”.
