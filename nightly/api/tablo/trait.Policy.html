Expand description

Decides which Abilitys the current user has over a resource’s records.

A closure |cx: &Cx, ability: Ability<'_, M>| -> bool is a policy, so a resource with one rule per ability matches on the ability. The building blocks in this module combine with their and and or methods; they are inherent rather than trait methods because a block such as Allow is a policy over every model, and a trait method would leave the model to infer.
