Expand description

Stores one uploaded file and names the value a record stores; installed once per panel with Panel::uploads.

filename arrives sanitized to a non-empty basename without directories or control characters; bytes are bounded by the 10 MiB form-body cap. The framework stores the returned path verbatim.

Stores bytes and returns the value to store; the Err string renders inside the field’s inline error, so it must be user-actionable.
