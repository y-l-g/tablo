tablo::panel

Module url 

Source
Expand description

URLs into the request’s panel, so app code never spells a prefix.

Each helper answers for the panel serving the request: the one whose prefix the request is under, or the only panel when the router mounts one. A resource or page that panel does not register has no URL there, and the helper returns None.

ⓘ
let posts = tablo::url::resource::<PostResource>(cx);  // Some("/admin/posts")
let media = tablo::url::page::<MediaLibraryPage>(cx);  // Some("/admin/media")
let home = tablo::url::panel(cx);                      // Some("/admin")
