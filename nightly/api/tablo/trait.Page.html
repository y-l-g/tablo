Expand description

A page the Panel mounts and lists in its sidebar.

Registered with Panel::page at {prefix}/{slug}, or with Panel::home at the panel prefix itself. The panel owns the route and the sidebar entry, the way it owns a Resource’s; the page owns its markup. The app’s #[layout] at the panel prefix frames it in the shell, as it frames every panel page.

ⓘ
struct ReportsPage;

impl Page for ReportsPage {
    async fn render(cx: &Cx) -> Result<impl View> {
        Ok(view! { cx => tablo_ui::page(tablo_ui::page_title("Reports")) })
    }
}

Panel::new("admin").page::<ReportsPage>() // GET /admin/reports

A page serves one GET and always has a sidebar entry. A form it renders posts to a route the app declares with #[route]; under the panel prefix, the auth gate covers it.

Provided Methods§

Source

fn slug() -> String

The URL segment under the panel prefix. Default: the type name without a Page suffix, kebab-cased (MediaLibraryPage → media-library).

Panel::home mounts the page at the prefix and does not read it.

Source

fn navigation_label() -> String

The sidebar label. Default: the type name without a Page suffix, in sentence case (MediaLibraryPage → Media library).

Source

fn navigation() -> NavigationItem

The sidebar entry. Override it to set the order or the icon; the panel resolves its URL, as it does for Resource::navigation.
