1//! Tablo — an admin toolkit for Rust, server-rendered on Topcoat and persisted
2//! with Toasty.
3//!
4//! This crate is the one Tablo dependency an app names, beside `topcoat` and
5//! `toasty` at the revisions Tablo pins. It re-exports
6//! [`tablo_core`] at its root, the UI components as [`ui`], and, with the
7//! `testing` feature, the in-memory HTTP client as `testing`. The derives
8//! (`RecordForm`, `EmbeddedForm`) work through this crate alone.
9//!
10//! ```toml
11//! [dependencies]
12//! tablo = { git = "https://github.com/y-l-g/tablo", features = ["sqlite"] }
13//!
14//! [build-dependencies]
15//! tablo-build = { git = "https://github.com/y-l-g/tablo" }
16//! ```
17//!
18//! The driver features (`sqlite`, `postgresql`, `mysql`) turn on Toasty's
19//! driver of the same name; the toolkit itself enables none. The app's
20//! `build.rs` calls `tablo_build::tailwind()`, which finds Tablo's sources
21//! through this crate. The user guide starts at "Your first panel".
22
23pub use tablo_core::*;
24#[cfg(feature = "testing")]
25pub use tablo_test as testing;
26pub use tablo_ui as ui;
