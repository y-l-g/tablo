1//! Tablo: a server-rendered admin toolkit on [Topcoat](topcoat) and [Toasty](toasty).
2//!
3//! A [`Panel`] serves one [`Resource`] per Toasty model. A resource declares its list page as a
4//! [`Table`], its create and edit forms as a [`Schema`] plus a
5//! [`RecordForm`](derive@RecordForm) struct the submission parses into, and its policy as `can_*`
6//! predicates that deny by default. The app mounts the panel on its own Topcoat router with
7//! [`RouterBuilderPanelExt::panel`], which checks every declaration first; one router mounts any
8//! number of panels at distinct prefixes.
9//!
10//! ```ignore
11//! pub struct BookResource;
12//!
13//! impl Resource for BookResource {
14//!     type Model = Book;
15//!     type Form = BookForm;
16//!
17//!     fn can_view_any(_cx: &Cx) -> bool {
18//!         true
19//!     }
20//!
21//!     fn table() -> Table<Book> {
22//!         Table::new(
23//!             |b: &Book| b.id.to_string(),
24//!             TextColumn::r#for(Book::fields().title(), |b: &Book| b.title.clone()).searchable(),
25//!         )
26//!     }
27//!
28//!     fn form(_dx: &crate::schema::DeclCx) -> Schema {
29//!         Schema::new(Field::text(Book::fields().title()))
30//!     }
31//! }
32//!
33//! let router = Router::builder()
34//!     .discover()
35//!     .app_context(db)
36//!     .panel(Panel::new("admin").resource::<BookResource>())?
37//!     .build();
38//! ```
39//!
40//! The [user guide](https://y-l.fr/tablo/nightly/guide/) walks through a complete panel and each
41//! part of it. [`Resource`] lists every item a resource can declare, and [`Panel`] every builder
42//! call.
