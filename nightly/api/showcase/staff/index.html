Module staff 

Source
Expand description

The people who sign in to the panel: the showcase’s own user table, with a seat in each blog (tenant) they work on.

StaffAuth is the one Authenticator the panel installs. It loads a Staff row with its seats into a SignedStaff, the panel’s user type, which app code reads back with auth::user::<SignedStaff>(cx).
