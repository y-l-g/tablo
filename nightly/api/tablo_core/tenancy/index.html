Tenancy: which tenant a request acts for, and how a resource’s rows belong to one.

A resource declares its Tenancy. A scoped one requires a tenant in every handler, and the framework ANDs <lens> = <tenant> onto every loader through scoped_query, so query stays the resource’s non-tenant scoping seam and no loader can drop the filter by omission.

tenant_id answers the request’s tenant: the tenant the panel’s signed-in user carries, unless a server-set Tenant request extension or a Tenant scoped value overrides it, so app middleware and Router::handle tests can set it deliberately. No request header supplies a tenant: learning another tenant’s UUID does not make anyone that tenant.
