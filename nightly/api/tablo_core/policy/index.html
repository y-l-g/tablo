Authorizes resource abilities, denying by default.

Combines Allow, Deny, ReadOnly, when, and closures with and/or.

ⓘ
fn policy() -> impl Policy<Post> {
    when(not_suspended).and(|_cx: &Cx, ability: Ability<'_, Post>| match ability {
        Ability::Update(post) | Ability::Delete(post) => !post.locked,
        _ => true,
    })
}

can asks a resource’s policy from app code, and can_list answers whether the current request may open a resource’s list at all.
