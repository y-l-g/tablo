pub fn wired_table<R: Resource>(cx: &Cx) -> Table<R::Model>
Expand description

The table the panel’s list page serves for R, for a page that owns its table instead of mounting the panel’s list route.

The page-owned seam (GH #154 §2) pairs this with TablePage::load and Table::render_with_state. The table carries R::table’s columns, key, page size, search toolbar and filter bar, plus the action chrome R’s declarations imply — the row Delete link and bulk column from can_delete_any, the Edit link from a record form (RecordForm::HAS_FORM) and the View link from viewed — each gated per row by can_view/can_update/can_delete, the wiring the panel’s own list applies. The chrome has no other entry point: a page-owned table that must agree with the resource’s routes takes its wiring from here.
