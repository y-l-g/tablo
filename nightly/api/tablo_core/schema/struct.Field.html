Struct Field

pub struct Field { /* private fields */ }
Expand description

One form field: a key, a label, the rules a submission meets, and the control that edits it.

A constructor picks the control and returns that control’s builder, which offers only the modifiers the control has, so a modifier on the wrong control does not compile. Each binds any lens a ResolvedLens accepts — a column (Post::fields().title()) or an embedded leaf (ResolvedLens::new(dx, Post::fields().seo().title())):

ⓘ
Field::text(User::fields().name()).placeholder("Ada Lovelace")   // TextField
Field::text(User::fields().email()).email().unique()
Field::text(User::fields().age())                  // typed: an `i64` column
Field::text(Post::fields().body()).multiline(6)
Field::choice(Post::fields().status()).options(Status::options()) // ChoiceField
Field::choice(Post::fields().author_id()).relationship::<AuthorResource>(..)
Field::file(Doc::fields().path())                                  // FileField
Field::toggle(Post::fields().featured())                           // CustomField

Every builder has label, required and optional. required defaults from the column’s nullability: a non-nullable column is required, so an empty submit fails inline instead of at the driver. .optional() opts out and .required() opts back in.

A modifier on the wrong control does not compile: options is a choice modifier, so it is not a method on a text field.

ⓘ
tablo_core::Field::text(User::fields().name()).options(["admin", "member"]);

A builder converts into a Field wherever a schema takes one (IntoSchema).

pub fn text<M, T>(lens: impl Into<ResolvedLens<M, T>>) -> TextField
where M: Model, T: FormScalar + IntoExpr<T> + 'static,

A text field over a column of any FormScalar type: String, a TypedValue type, or an Option of one.

The control renders the stored value, and a typed column adds its spelling rule:

  • a submission the type refuses is an inline field error naming the input (`2024-13-01` is not a valid timestamp);
  • what is stored is the type’s own spelling of the parsed value, so a value re-submitted unchanged is written back in the shape it was read.

The control’s type is the type’s INPUT_TYPE: datetime-local for a jiff::Timestamp, whose stored instant renders in UTC and whose submission is read back as UTC, and text otherwise (email overrides it). unique defaults from the column’s unique index.

T is IntoExpr of itself so the unique probe compares the parsed value through the lens rather than its text.

pub fn choice<M, T>(lens: impl Into<ResolvedLens<M, T>>) -> ChoiceField
where M: Model,

A choice field over a column of any type, often a foreign key (Post::fields().author_id()).

A bare choice validates presence only; its options come from options or relationship, which also checks that a submitted key exists, tenant-aware.

pub fn file<M>(lens: impl Into<ResolvedLens<M, String>>) -> FileField
where M: Model,

A file field over a String column holding the uploaded file’s path, never its bytes.

A form holding one renders enctype="multipart/form-data", and the POST parser extracts the file part; where the bytes go is the app’s decision, expressed by the Uploader installed with Panel::uploads. With none, the sanitized basename is stored. The file input renders no value attribute, which browsers ignore for security, so an edit form shows the stored path and a clear_<field> checkbox beside an empty input, and the input is required only while nothing is stored.

pub fn toggle<M>(lens: impl Into<ResolvedLens<M, bool>>) -> CustomField
where M: Model,

A checkbox over a bool column: the built-in Toggle.

An unchecked box submits false, so the field is never empty and carries no required marker.

pub fn custom<M, T>( lens: impl Into<ResolvedLens<M, T>>, control: impl Control + 'static, ) -> CustomField
where M: Model, T: FormScalar,

A field over a column of any FormScalar type, rendered by an app’s Control.

The field keeps the shared rules: the required default from the column’s nullability, the type’s parse rule, and the error slot. The control renders only the input.
